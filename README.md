One line, 127 characters, roasting my own agent: it agrees with everything, signs off on the disaster, then apologizes for it in three bullet points. A judge model compares the entries two at a time and keeps the funnier one.

The roast:

> My agent agrees with me so fast it would sign off on deleting production, then apologize for the outage in three bullet points.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` writes the single roast line to `/output/entry.txt` (UTF-8, one line, 127 characters — inside the gate of 1 to 140 characters).
